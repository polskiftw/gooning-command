DGD 03 — ADD ALL EIGHT GITHUB SECRETS
=====================================

These values stay private even though the repository is public.
Do not paste any of them into settings.json, app.py, the workflow file,
or any normal file in the repository.

OPEN THE SECRET PAGE
--------------------
1. Open your GitHub repository.
2. Click Settings near the top.
3. In the left sidebar, click Secrets and variables.
4. Click Actions.
5. Stay under Repository secrets.
6. Click New repository secret.

You will repeat that process EIGHT times.

SECRET 1 OF 8
-------------
Name:
R2_ACCOUNT_ID

Value:
Paste your Cloudflare Account ID.

It usually looks like a long string of letters and numbers.
Do not paste the full R2 endpoint URL here.

Click Add secret.

SECRET 2 OF 8
-------------
Name:
R2_ACCESS_KEY_ID

Value:
Paste the value Cloudflare labeled Access Key ID.

Click Add secret.

SECRET 3 OF 8
-------------
Name:
R2_SECRET_ACCESS_KEY

Value:
Paste the value Cloudflare labeled Secret Access Key.

Click Add secret.

SECRET 4 OF 8
-------------
Name:
R2_BUCKET_NAME

Value:
Type the exact name of your R2 bucket.

Example fake value:
gooning-party-media

Click Add secret.

SECRET 5 OF 8
-------------
Name:
REDDIT_COOKIES_BASE64

Value:
Open REDDIT_COOKIES_BASE64.txt on your PC.
Copy the entire single long line.
Paste it here.

Do not include the filename.
Do not add quotation marks.
Do not add spaces before or after it.

Click Add secret.

SECRET 6 OF 8
-------------
Name:
TS_OAUTH_CLIENT_ID

Value:
Paste the Tailscale OAuth Client ID created in DGD 12.

This is a Tailscale value, not a Reddit value.

Click Add secret.

SECRET 7 OF 8
-------------
Name:
TS_OAUTH_SECRET

Value:
Paste the Tailscale OAuth Client Secret created in DGD 12.

Tailscale may show this secret only once.

Click Add secret.

SECRET 8 OF 8
-------------
Name:
TS_EXIT_NODE_IP

Value:
Paste the Flint 2 Router Virtual IP shown on its Tailscale page.

For your current router setup, the value is:
100.124.207.6

Do not add http://
Do not add https://
Do not add a slash.
Do not add spaces.

Click Add secret.

FINAL CHECK — DO NOT SKIP
-------------------------
GitHub must show these exact eight repository-secret names:

R2_ACCOUNT_ID
R2_ACCESS_KEY_ID
R2_SECRET_ACCESS_KEY
R2_BUCKET_NAME
REDDIT_COOKIES_BASE64
TS_OAUTH_CLIENT_ID
TS_OAUTH_SECRET
TS_EXIT_NODE_IP

Count them. There must be 8.

GitHub will not show their values afterward. That is normal.

NOT A SECRET USED BY THIS BUILD
-------------------------------
Do not create R2_ENDPOINT for this build.
The app creates the endpoint itself from R2_ACCOUNT_ID.

Do not create TAILSCALE_EXIT_NODE.
The exact name used by the workflow is TS_EXIT_NODE_IP.
