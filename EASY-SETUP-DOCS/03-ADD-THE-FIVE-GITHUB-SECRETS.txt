DGD 03 — ADD THE FIVE GITHUB SECRETS
====================================

These values stay private even though the repository is public.
Do not paste them into normal repository files.

OPEN THE SECRET PAGE
--------------------
1. Open your GitHub repository.
2. Click Settings near the top.
3. In the left sidebar, click Secrets and variables.
4. Click Actions.
5. Click the Repository secrets tab if it is not already selected.
6. Click New repository secret.

You will repeat that process five times.

SECRET 1
--------
Name:
R2_ACCOUNT_ID

Value:
Paste your Cloudflare Account ID.

Click Add secret.

SECRET 2
--------
Name:
R2_ACCESS_KEY_ID

Value:
Paste the R2 Access Key ID.

Click Add secret.

SECRET 3
--------
Name:
R2_SECRET_ACCESS_KEY

Value:
Paste the R2 Secret Access Key.

Click Add secret.

SECRET 4
--------
Name:
R2_BUCKET_NAME

Value:
Type the exact R2 bucket name.

Click Add secret.

SECRET 5
--------
Name:
REDDIT_COOKIES_BASE64

Value:
Open REDDIT_COOKIES_BASE64.txt on your PC.
Copy the entire single long line.
Paste it here.

Do not include the filename.
Do not add quotation marks.
Do not add spaces before or after it.

Click Add secret.

FINAL CHECK
-----------
The secret list must show these exact five names:

R2_ACCOUNT_ID
R2_ACCESS_KEY_ID
R2_SECRET_ACCESS_KEY
R2_BUCKET_NAME
REDDIT_COOKIES_BASE64

GitHub will not show their values afterward. That is normal.
