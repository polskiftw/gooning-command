DGD 05 — PUT THE WEBSITE ON CLOUDFLARE
======================================

PART A — CREATE THE WORKER
--------------------------
1. Open the Cloudflare dashboard.
2. Open Workers & Pages.
3. Click Create.
4. Choose Worker.
5. Give it a name such as:

   gooning-party-fresh

6. Deploy the starter Worker.
7. Open Edit code.

PART B — REPLACE THE CODE
-------------------------
1. Open this project folder on your PC.
2. Open:

   worker/worker.js

3. Select all of its contents.
4. Copy it.
5. In Cloudflare's editor, select all starter code.
6. Paste worker.js over it.
7. Click Deploy.

PART C — CONNECT THE R2 BUCKET
------------------------------
1. Open the Worker's Settings.
2. Find Bindings.
3. Add an R2 bucket binding.
4. Set the variable/binding name EXACTLY to:

   MEDIA_BUCKET

5. Select your real R2 bucket.
6. Save or deploy the binding.

PART D — CONNECT THE BASE DOMAIN
--------------------------------
1. Open the Worker's Settings.
2. Open Domains & Routes.
3. Add a Custom Domain.
4. Enter your base domain:

   gooning.party

5. Confirm it.

The website stays at:

https://gooning.party/

The R2 prefix gallery/ is invisible storage organization. It does not make the
website live at /gallery/.
