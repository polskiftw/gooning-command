DGD 06 — TEST EVERYTHING
========================

TEST 1 — R2
-----------
Open your R2 bucket in Cloudflare.
You should eventually see:

  gallery/
  gallery-index.json
  _internal/gallery-dl-archive.sqlite3

The gallery/ section contains media.
The _internal file remembers what gallery-dl already processed.
Do not delete it unless you deliberately want the downloader to forget its history.

TEST 2 — WEBSITE
----------------
Open:

https://gooning.party/

You should see one random media item.

Test these controls:
- click Next random
- press Space
- press F
- click the media to toggle fit/native size
- try the extension filter

Videos should loop, play muted, and show no controls.

TEST 3 — SECOND ACTION RUN
--------------------------
Run the GitHub workflow manually a second time.
It should restore the history file and avoid reprocessing the same Reddit items.
This is download-history tracking, not an image duplicate checker.
