DGD 08 — TROUBLESHOOTING
========================

THE ACTIONS TAB SHOWS NO WORKFLOW
--------------------------------
Confirm the repository contains this exact path:

.github/workflows/download-cats.yml

If .github is missing, upload that folder.

THE RUN FAILS WITH CHANGE_THIS_SUBREDDIT
----------------------------------------
You did not replace all three placeholders in settings.json.
Edit them and commit the change.

THE RUN SAYS A SECRET IS MISSING
--------------------------------
GitHub repository > Settings > Secrets and variables > Actions.
Confirm all five exact names exist:

R2_ACCOUNT_ID
R2_ACCESS_KEY_ID
R2_SECRET_ACCESS_KEY
R2_BUCKET_NAME
REDDIT_COOKIES_BASE64

THE RUN SAYS COOKIES ARE INVALID
--------------------------------
Update REDDIT_COOKIES_BASE64 with the entire one-line contents of the Base64 file.
Do not paste the readable reddit-cookies.txt file there.

THE RUN GETS REDDIT 401/403 ERRORS
----------------------------------
Your Reddit cookies may have expired or been revoked.
Export fresh cookies, make a new Base64 value, and update the GitHub secret.

THE ACTION IS GREEN BUT THE WEBSITE SAYS NO MEDIA
--------------------------------------------------
1. Check the R2 bucket for gallery-index.json.
2. Check that the Worker has an R2 binding named exactly MEDIA_BUCKET.
3. Confirm the Worker binding points to the same bucket used by GitHub Actions.
4. Wait one minute and reload the website.

THE WEBSITE IS AT THE WRONG ADDRESS
-----------------------------------
Add gooning.party as the Worker's Custom Domain under Domains & Routes.
The base-domain website is correct. You do not visit /gallery/.

A SCHEDULED RUN STARTED LATE
----------------------------
GitHub scheduled jobs are not exact timers. A run can start a few minutes late.
Nothing is broken.

THE PUBLIC REPOSITORY SHOWS MY SUBREDDIT NAMES
----------------------------------------------
That is expected because settings.json is public.
Your secret keys and cookies remain private only if you stored them as Actions secrets.

I ACCIDENTALLY UPLOADED A COOKIE OR SECRET FILE
-----------------------------------------------
Immediately revoke/replace that credential. Deleting the file from the newest commit
is not enough because Git history may still contain it.
