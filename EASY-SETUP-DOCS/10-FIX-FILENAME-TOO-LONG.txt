FIX "FILE NAME TOO LONG"
========================

You saw something like:

  OSError: [Errno 36] File name too long

Do this:

1. Open this v0.2.2 folder.
2. Find app.py.
3. Open your GitHub repository.
4. Upload this new app.py to the repository's main/root page.
5. Let GitHub replace the old app.py.
6. Click Commit changes.
7. Go to Actions.
8. Open the downloader workflow.
9. Click Run workflow.

That is all.

The downloader now uses short post/media-ID filenames instead of giant Reddit
titles. You do not need to change settings.json or any GitHub secret.
