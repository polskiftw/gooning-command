GOONING PARTY FRESH v0.2.2
===========================

FIXED: "File name too long" DOWNLOAD ERRORS

Some Reddit posts have enormous titles. gallery-dl could try to use those titles
as local filenames, exceeding Linux's filename limit before our upload code ever
saw the file.

v0.2.2 forces gallery-dl to use short names built from:

  extractor category + stable post/media ID + gallery item number + extension

If no ID exists, the original filename is truncated to 80 characters.

WHAT TO REPLACE ON GITHUB
-------------------------
Replace only the root-level app.py with this package's app.py, commit it, then
run the workflow again. Nothing else needs changing.
