GOONING PARTY FRESH v0.2.3
===========================

This update adds the Reddit pacing and scan-depth controls requested after the first runs.

WHAT CHANGED
------------
- GitHub Actions now runs every 15 minutes instead of every 10 minutes.
- Each subreddit scan checks only the newest configured number of posts (default 50).
- A random delay is used between extraction requests (default 2 to 4 seconds).
- HTTP 429 responses pause before retrying (default 60 seconds).
- A subreddit scan stops after a configured number of consecutive archived skips (default 15).
- All of these knobs live in settings.json.

FILES TO REPLACE ON GITHUB
--------------------------
1. app.py
2. settings.json
3. .github/workflows/download-cats.yml

You do not need to change any GitHub secrets or Worker files.
